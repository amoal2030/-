# تطبيق «حوّلها» (Hawwilha) 💡
> **«ما تملكه اليوم قد يكون فرصتك للغد»**

تطبيق ويب عربي متكامل واحترافي يساعدك على اكتشاف طرق الاستفادة من مقتنياتك ومواردك ومهاراتك وأوقاتك المتاحة، وتحويلها إلى:
1. **مصدر دخل سريع**
2. **فكرة مشروع تجاري**
3. **خدمة يمكن بيعها**
4. **طريقة لتوفير المال**
5. **فرصة لإعادة استخدام الموارد بطريقة مبتكرة**

---

## 🌟 مميزات التطبيق

* **واجهة عربية بالكامل (RTL)** متوافقة مع أحدث معايير تجربة المستخدم.
* **تقنيات ويب نقية 100%**: مبني باستخدام **HTML5** و **CSS3** و **JavaScript Vanilla فقط** دون أي مكتبات أو أطر عمل ثقيلة (لا React ولا Vue ولا Angular).
* **قابل للتشغيل مباشرة في المتصفح**: يمكنك فتح ملف `index.html` في أي متصفح وسيعمل فورًا.
* **محرك تحليل محلي ذكي (Offline Engine)**: يحلل مدخلاتك ويطابقها مع مئات السيناريوهات والفرص بناءً على الكلمات المفتاحية والميزانية وساعات الفراغ والهدف ومستوى الخبرة دون الحاجة لخادم.
* **خطط تنفيذ تفصيلية (7-Day Action Plan)**: لكل فرصة خطة عمل يومًا بيوم، نص إعلان جاهز للنشر، خطوات الحصول على أول عميل، التسعير المقترح، والمخاطر.
* **حفظ الأفكار محليًا**: إمكانية حفظ الأفكار المفضلة في المتصفح عبر `LocalStorage`.
* **مشاركة ونسخ فوري**: نسخ الخطط ونصوص الإعلانات بضغطة زر مع دعم مشاركة النظام عبر `Web Share API`.
* **الوضع الليلي والنهاري (Dark / Light Mode)** مع حفظ اختيار المستخدم.
* **تصميم متجاوب بالكامل** يعمل على شاشات الهواتف الذكية، الأجهزة اللوحية، والحواسيب.

## 📂 هيكلة ملفات المشروع

```text
├── index.html               # الملف الشامل والمستقل الجاهز للنشر المباشر على GitHub Pages بنقرة واحدة (HTML + CSS + JS مدمج)
├── hawwilha-standalone.html # نسخة احتياطية من الملف المستقل الموحد
├── template.html            # قالب HTML المفصول للاستخدام مع الملفات المقسمة
├── style.css                # ملف التنسيقات والأنماط (CSS3)
├── app.js                   # ملف المنطق وإدارة الواجهة التفاعلية (Vanilla JS)
├── ai.js                    # محرك تحليل الموارد وقواعد المعرفة (Offline Engine)
├── build-standalone.js      # سكريبت أتمتة اختياري لدمج أي تعديلات في index.html
└── README.md                # دليل التشغيل والتطوير والنشر الشامل
```

> **ملاحظة مهمة للاستضافة على GitHub Pages:**
> ملف `index.html` أصبح الآن ملفًا موحدًا وشاملاً (All-in-One Standalone HTML)؛ يمكنك ببساطة رفع ملف `index.html` مباشرة إلى مستودعك على GitHub وتفعيل GitHub Pages ليعمل التطبيق فورًا 100% دون أي خطأ في مسارات الملفات أو مشاكل أذونات المتصفح.

## 🚀 1. كيف تشغّل التطبيق على جهازك

التطبيق مصمم ليعمل مباشرة بدون أي خطوات تثبيت معقدة:

### الطريقة الأولى (المباشرة والأسهل):
1. قم بتحميل أو نسخ ملفات المشروع إلى مجلد واحد على جهازك.
2. انقر نقرًا مزدوجًا على ملف `index.html` لفتحه في متصفحك المفضل (Google Chrome، Safari، Edge، Firefox).
3. سيعمل التطبيق بكامل وظائفه فورًا!

### الطريقة الثانية (باستخدام خادم محلي خفيف - اختياري):
إذا كنت تستخدم محرر أكواد مثل VS Code وتريد ميزة التحديث المباشر:
- يمكنك تثبيت إضافة **Live Server** في VS Code ثم النقر بالزر الأيمن على `index.html` واختيار **Open with Live Server**.
- أو عبر سطر الأوامر بواسطة Python:
  ```bash
  # لأجهزة Mac / Linux / Windows
  python3 -m http.server 3000
  ```
  ثم افتح الرابط: `http://localhost:3000`

## 🎨 2. كيف تعدّل التصميم والألوان

جميع عناصر التصميم مبنية باستخدام **متغيرات CSS (CSS Variables)** في بداية ملف `style.css`:

### تعديل الألوان الرئيسية:
افتح ملف `style.css`، وستجد في السطور الأولى:
```css
:root {
  /* اللون الرئيسي (الافتراضي هو الأخضر الزمردي) */
  --primary: #059669;
  --primary-hover: #047857;
  --primary-light: #d1fae5;
  
  /* خلفيات الوضع الفاتح */
  --bg-main: #f8fafc;
  --bg-surface: #ffffff;
}

/* خلفيات وألوان الوضع الليلي */
[data-theme="dark"] {
  --bg-main: #0b1323;
  --bg-surface: #141f36;
  --primary: #10b981;
}
```
* لتغيير لون التطبيق مثلاً إلى اللون الأزرق الملكي:
  غيّر قيمة `--primary` إلى `#2563eb` أو أي لون تفضله.

### تعديل الخط العربي:
في ملف `index.html` تم تضمين خطي `Tajawal` و `Cairo` من Google Fonts. يمكنك استبدال الرابط بأي خط عربي تفضله (مثل `Readex Pro` أو `Almarai`) وتحديث سطر الخط في `style.css`:
```css
body {
  font-family: 'Tajawal', 'Cairo', system-ui, sans-serif;
}
```

## 🤖 3. كيف تضيف Google Gemini API بطريقة آمنة مستقبلاً

تم إعداد ملف `ai.js` ليكون جاهزًا للربط بالذكاء الاصطناعي السحابي بسهولة تامة مع مراعاة الأمان العالي.

### القواعد الذهبية لأمان مفاتيح API:
⚠️ **تحذير أمني**: لا تضع مفتاح API في كود المتصفح الأمامي المتاح للعموم على الإنترنت؛ لأن أي زائر يمكنه استخراجه من أدوات المطور (F12).

### الطريقة الموصى بها (خادم وسيط Backend Proxy):
1. **إنشاء خادم مصغر** (باستخدام Node.js/Express أو Cloudflare Workers أو Vercel/Netlify Serverless Function):
   - يقرأ المفتاح السري بأمان من متغيرات البيئة: `process.env.GEMINI_API_KEY`.
   - يستقبل مدخلات المستخدم من التطبيق، ويخاطب Gemini API، ثم يعيد النتائج بتنسيق JSON.

2. **ربط التطبيق بالخادم الوسيط في ملف `ai.js`**:
   افتح ملف `ai.js` وعدّل الإعدادات في بداية الملف:
   ```javascript
   export const AI_CONFIG = {
     // ضع رابط نقطة النهاية في خادمك
     backendEndpoint: '/api/generate',
     // فعّل الاتصال السحابي
     useCloudAI: true,
     apiKey: '' // دعه فارغًا لأن الخادم يتولى المفتاح
   };
   ```

### طريقة التجربة الشخصية المحلية (Local Development):
إذا كنت تجرب التطبيق محليًا على جهازك الخاص فقط ولن تنشره للعامة:
1. احصل على مفتاح مجاني من [Google AI Studio](https://aistudio.google.com/).
2. افتح `ai.js` وضع المفتاح في `AI_CONFIG.apiKey` واجعل `useCloudAI: true`.
3. سيبدأ التطبيق فورًا في استدعاء الذكاء الاصطناعي وتوليد خطط غير محدودة!

## 🌐 4. كيف تنشر التطبيق مجانًا للعالم

نظرًا لأن التطبيق يتكون من ملفات ثابتة (Static HTML/CSS/JS)، يمكنك نشره مجانًا في ثوانٍ:

### النشر عبر GitHub Pages:
1. أنشئ مستودعًا جديدًا (Repository) على حسابك في GitHub وارفعه كود المشروع إليه.
2. اذهب إلى إعدادات المستودع (**Settings**) -> ثم تبويب **Pages**.
3. تحت قسم **Branch**، اختر الفرع الرئيسي `main` ثم المجلد `/ (root)` واضغط **Save**.
4. خلال دقيقة واحدة، سيعطيك GitHub رابطًا مباشرًا يعمل على مستوى العالم مجانًا وبشهادة أمان SSL!

### النشر عبر Netlify (سحب وإفلات في 10 ثوانٍ):
1. سجل دخولك على [Netlify](https://www.netlify.com/).
2. اذهب إلى قسم **Sites** واسحب مجلد المشروع بالكامل وأفلته في المربع المخصص (**Drag & Drop**).
3. ستحصل فورًا على رابط مباشر جاهز ومجاني!
